# 7 大变换维度详解（SCAMPER-LP · prompt 适配版）

> 每条变换都配 prompt 场景的真实示例 + 风险标注。
> 配套使用：从 7 维里选 **2-3 个不重叠** 的变换组合使用，效果最佳。

---

## 1 · Substitute 替代

**含义**：把原 prompt 中的某个关键元素替换成另一个，但保持钩子不变。

**常见替换轴**：

| 轴 | 原 | 替 |
|---|---|---|
| 情绪对象 | 关爱 → 理解 | "请关注" → "请陪伴" |
| 价值载体 | 点赞 → 转发 | "给我点赞" → "转给身边人" |
| 互动类型 | 求鼓励 → 求分享 | "给我鼓励" → "也分享你的故事" |
| 主角身份 | 军人 → 警察 → 消防员 → 护士 → 教师 | 同模板换制服 |
| 目标对象 | 流浪狗 → 流浪猫 → 老兵 → 留守儿童 | 同情感换承载 |

**风险**：如果只 Substitute 一个维度，等于换皮，平台会判同质化。

---

## 2 · Combine 合并

**含义**：把两个本来不相关的爆款套路杂交，生成新钩子。

**示例杂交组合**：

- 军人×萌宠（"军人 + 退役军犬 + 最后一个任务"）
- 亲情×美食（"妈妈 + 学做家乡菜 + 童年回忆"）
- 历史×现代（"老兵 + 当下青年 + 隔空对话"）
- 灾难×日常（"消防员 + 出警前 + 给女儿的视频日记"）
- 老龄×萌娃（"98 岁奶奶 + 教孙子 + 上世纪的故事"）

**风险**：杂交的两个套路必须有**共同的情感底层**，否则观众觉得突兀。

---

## 3 · Adapt 跨域改造

**含义**：把原 prompt 的叙事**搬到完全不同的语境**，但保留张力结构。

**示例**：
- 纪实催泪 → 治愈系轻喜（同样的"离别"骨架，反转情绪色彩）
- 求鼓励 → 反向"请别打扰"（保持"情感诉求"结构，但反转方向）
- 战争 → 职场（同样的"压力+坚持"，换到打工人语境）

**风险**：Adapt 必须保持**底层情感张力**不变，否则失去原作灵魂。

---

## 4 · Modify 放大

**含义**：把原 prompt 中某个**不起眼的细节**放大成主线钩子。

**示例**：
- 原 prompt 里"爷爷的开衫洗得发白" → 新 prompt 里整段围绕"这件开衫陪伴爷爷 60 年的故事"
- 原 prompt 里"小姑娘的眼泪" → 新 prompt 里"这滴眼泪背后的故事 + 镜头慢放"

**风险**：放大的细节必须有**足够的叙事容量**，否则撑不起整个 prompt。

---

## 5 · Put 挪作他用

**含义**：把原 prompt 的某种**机制**挪到完全不同的主题。

**示例**：
- "退休送别"机制 → "宠物临终送别"
- "军人不舍"机制 → "异地恋分手"
- "等待归来"机制 → "异地求学，等孩子回来"

**风险**：挪过去后必须确保**目标主题能承载这个情感**，否则不伦不类。

---

## 6 · Eliminate 删减

**含义**：删掉一个"理所当然"的元素，看看 prompt 是否还能爆。

**可尝试删除的元素**：
- 删"求鼓励/求点赞"的口播
- 删背景音乐描述
- 删特写镜头的某部分
- 删台词中的一句话
- 删"模型 2.0/9:16"等技术规格（看是否影响生成效果）

**风险**：删完要确保核心钩子还在；如果删完还成立，说明这个元素本就是冗余的；如果删完就垮了，说明它是核心。

> ⚠️ 这是最容易出反模式"过度删减"导致失去张力的变换，用时要谨慎。

---

## 7 · Reverse 反转

**含义**：把原 prompt 中的某个**默认假设**反过来。

**可反转的维度**：
- 情绪方向（催泪 ↔ 治愈 / 求关注 ↔ 求放手）
- 互动方向（主角向观众 ↔ 观众向主角）
- 角色地位（强者 ↔ 弱者 / 主角 ↔ 配角）
- 时间方向（回忆 ↔ 未来 / 等待 ↔ 寻找）

**风险**：反转后必须确保**情感共鸣不流失**，否则变成"为反而反"。

---

## 组合策略（推荐）

不重叠组合，效果最佳：

| 组合 | 适用 |
|---|---|
| Substitute + Modify | 换情绪对象 + 放大细节 → 稳健 |
| Substitute + Reverse | 换钩子 + 反转方向 → 大胆 |
| Combine + Adapt | 杂交套路 + 跨域改造 → 破圈 |
| Eliminate + Modify | 删冗余 + 放大隐藏宝藏 → 精细 |

避免组合：
- Substitute + Substitute（同维度叠加无意义）
- Eliminate + Reverse（容易把钩子彻底改没）

## 自检表（每次选完变换后必过）

- [ ] 我选的 2-3 个变换不重叠吗？
- [ ] 每个变换后，钩子是否还在？
- [ ] 是否有至少 1 个变换是**深层**的（不是单纯换皮）？
- [ ] 改完后 prompt 还能用一句话说清核心张力吗？
