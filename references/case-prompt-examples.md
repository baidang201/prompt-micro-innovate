# Prompt 微创新实战案例

> 3 个真实案例，展示完整的"识别钩子 → 选变换 → 写新 prompt → 三问铁律"流程。
> 案例均来自用户提供的抖音爆款 prompt 样本（2026-08-07）。

---

## 案例 1 · 老爷爷收养流浪狗 → 退休女教师收养流浪猫

### 输入
```
帮我生成一个视频：9:16竖屏，固定画面，纪实催泪。初冬郊区，几户茅草房身后是大深山区。98岁老爷爷，深蓝色破旧开衫，领口一颗扣子没扣露出灰色磨毛薄毛衣，洗得发白。头上戴破旧帽子，帽檐微垂有点破烂。脚下磨旧黑色矮筒水鞋，沾着田间泥土。满脸沟壑皱纹，眼神温和有力量。他收养了很多流浪狗，站在竹子围栏旁边。围栏比他还高，里面数不清的小狗，白的、黑的、黄的什么品种都有。有的小狗在睡觉，有的在打架，有的站起来趴在围栏上。有少许破旧棉被当狗窝，有几个大小不一缺了一半的碗，一个装着一半狗粮，一个装满水，情节真实，小狗面部不畸形。长镜头缓缓推近，全程固定机位。山风轻轻吹过，吹动鬓角白发。远处青山连绵，山间薄雾淡淡升起。老人抬眼望向镜头，指着围栏：这些都是我捡回来的小狗，看着它们可怜，就领回来了。顿了顿，手轻轻摸了摸围栏：路过的朋友们，能给我一个鼓励吗？让更多的人关爱流浪狗。手臂因年迈微微颤抖，指节粗糙、指甲缝都是泥巴，布满老茧与伤痕，但那一刻脊背挺得像身后的青山一样笔直。口型对上，语速跟上，无背景音乐，模型2.0，比例9:16，时长10秒。
```

### Step 1 · 识别钩子
- **核心钩子 A**：**未完成承诺 + 反向诉求**（"我领回来了，你们能不能给我鼓励"——既是承诺又是请求）
- **核心钩子 B**：**底层反差**（98岁老爷爷 + 收养流浪狗 = 反差萌 + 共情）

### Step 2 · 选变换
| 维度 | 变换 | 说明 |
|---|---|---|
| Substitute 替代 | 关爱流浪狗 → 求领养 | 钩子从"被动求关注"变成"主动求行动"，更易传播 |
| Combine 合并 | 山区+动物 → 上海老弄堂+流浪猫 | 跨域杂交，新鲜感强 |
| Modify 放大 | "指甲缝都是泥巴"细节保留 | 改写后保留同款"手部细节"作为护城河 |

### Step 3 · 写新 prompt
```
帮我生成一个视频：9:16竖屏，固定机位，纪实暖心。深秋的上海老弄堂，灰砖墙后晾着万国旗，几户老式石库门后是外滩天际线若隐若现。72岁退休女教师，褪色碎花棉袄，灰色毛线背心，蓝色头巾盘住满头白发，老北京布鞋沾着弄堂里的煤渣和梧桐落叶。满眼细纹但目光温柔。她收养了十几只流浪猫，站在一座旧木板钉成的三层猫窝旁。猫窝比她还高，窝里卧着大大小小的猫，花的、黑的、橘的什么花色都有。有的小猫在打盹，有的在伸懒腰，有的探出头朝她喵喵叫。窝里铺着旧毛衣和旧报纸，窝下放着几个缺角的塑料碟，一个装着一半猫粮，一个装满清水，细节真实，小猫面部不畸形。长镜头从弄堂口缓缓推进，全程固定机位对准她的正面。弄堂风穿堂而过，吹动她鬓角散落的白发。远处外滩的灯光慢慢亮起，黄浦江汽笛声低低传来。她抬眼望向镜头，指着猫窝：这些小家伙，都是我从雨里捡回来的。看着它们眼睛里的光，就舍不得放下了。顿了顿，手轻轻摸了摸猫窝的旧木板：朋友们，如果你正好想养一只猫，来找我吧，给它一个家，也给自己一个伴。双手因关节炎微微颤抖，指尖沾着猫毛和旧报纸的油墨，指节粗糙布满老茧，但那一刻背挺得笔直，像讲台上站了四十年的样子。口型严格同步，语速跟上，无背景音乐，模型2.0，比例9:16，时长10秒，镜头从弄堂口远景缓缓推到奶奶正面中近景。
```

### Step 4 · 三问铁律
- ① 钩子还在？✅ "未完成承诺+反向诉求"保留（找领养人）
- ② 决策空间更多？✅ 镜头调度更丰富（远景推近 vs 原版单点机位）
- ③ 跨过半衰期？✅ 观众不会立刻联想到老爷爷版本（人物身份/地点/动物/钩子全换了）

### 相似度
- 与原始：18.11%（Jaccard-2gram）
- 与历史：0%（空历史）

## 案例 2 · 中国海军军舰 → 高原边防军人 + 暴风雪（Combine 范式）

### 输入（节选）
```
帮我生成一个视频：一望无际的大海，海上刮起的风暴，电闪雷鸣不断。...我们是中国海军，能不能给我们一点鼓励？...
```

### Step 1 · 识别钩子
- **核心钩子 A**：**反向诉求**（"能不能给我们一点鼓励"）
- **核心钩子 B**：**极端环境+钢铁意志**（风暴中的军舰 + 海军）

### Step 2 · 选变换
| 维度 | 变换 | 说明 |
|---|---|---|
| Substitute 替代 | 大海 → 高原雪山 | 环境维度切换 |
| Modify 放大 | "电闪雷鸣" → "暴风雪+零下30度+手指冻僵" | 极端感放大 |
| Reverse 反转 | 海军公开喊话 → 边防战士给家人的私语 | 互动方向反转（从群体→个体） |

### Step 3 · 写新 prompt（节选）
```
帮我生成一个视频：9:16竖屏，4K电影画质。帕米尔高原，零下30度的暴风雪夜。远景是连绵雪峰和哨所窗户透出的昏黄灯光。镜头缓缓推近，哨所门口站着一位年轻边防兵，脸被冻得通红，睫毛结着冰霜，嘴唇干裂。他手里攥着一张揉皱的全家福照片，特写——照片里母亲抱着刚出生的小女儿。暴风雪呼啸中，他对着镜头，声音被风雪打碎，但眼神坚定：妈，今年又回不去了。小妹应该会叫哥哥了吧。能不能... 给边防军人一点鼓励。镜头慢慢拉远，哨所的灯光在风雪中变成一个小点。...
```

### Step 4 · 三问
- ① 钩子还在？✅ "求鼓励"保留 + 高原战士+家人张力更强
- ② 决策空间更多？✅（可换家庭背景、可换季节、可换人物年龄）
- ③ 跨过半衰期？✅（海军题材已严重饱和，高原边防是新角度）

## 案例 3 · 老机长退休 → 30 年公交车司机最后一次发车（Adapt 范式）

### 输入（节选）
```
帮我生成一个视频：...今天是我最后一次完成飞行任务，终于圆满收官了，要退休了，希望大家能为我送上祝福！...
```

### Step 1 · 识别钩子
- **核心钩子 A**：**见证时刻 + 未完成承诺**（最后一次飞行 + 求祝福）
- **核心钩子 B**：**职业反差**（机长专业形象 + 退休温情）

### Step 2 · 选变换
| 维度 | 变换 | 说明 |
|---|---|---|
| Adapt 改造 | 蓝天 → 城市街道（航空 → 公交） | 跨域，保持"最后一次"张力结构 |
| Substitute 替代 | "飞行" → "末班车" | 钩子具体化 |
| Modify 放大 | "6 位空乘" → "满车乘客的告别" | 把配角放大成群像 |

### Step 3 · 写新 prompt（节选）
```
帮我生成一个视频：9:16竖屏，固定机位。傍晚 6 点，老城区 29 路公交总站。一辆开了 30 年的老旧公交车缓缓进站，车身掉漆写着"29 路"。司机是位 58 岁的老师傅，今天是他最后一次发末班车。他穿着整齐的蓝色制服，胸前的工牌磨得字都看不清。镜头从车头摇到车厢——最后一排坐着几位熟客乘客，有位每天放学坐这趟车回家的小学生、有位去医院复查的老人、有位背着大包小包的外来务工者。车停稳后，老师傅慢慢站起来，走向车门口，对着镜头（也是对着乘客），声音有点哽咽：开了 30 年末班车，路上你们就是我的家人。今天最后一趟了... 大家能给我送个祝福吗？小学生第一个站起来鼓掌，老人默默擦了擦眼睛。...
```

### Step 4 · 三问
- ① 钩子还在？✅ "最后一次+求祝福"完整保留
- ② 决策空间更多？✅（公交场景的群像远比机场空乘丰富）
- ③ 跨过半衰期？✅（退役机长模板已被多账号吃透，公交车司机是新切入）

## 经验总结

1. **核心钩子不要动** —— 反向诉求/见证时刻/未完成承诺 是 3 类最高频爆款钩子，保留它们是底线
2. **至少 1 个变换是深层的** —— Substitute/Adapt/Reverse 这 3 个里至少选 1 个，不能只换皮
3. **护城河细节来自"土"** —— "指甲缝的泥巴" "讲台站了 40 年" "29 路的掉漆" —— 这些是 AI 套话写不出的，必须有真实生活观察
4. **新 prompt 应该比原 prompt 更长 / 更细** —— 微创新不是简化，是深化
